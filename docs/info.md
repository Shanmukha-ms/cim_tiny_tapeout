# Binary Neural Network — Breast Cancer Classifier

## How it works

This design implements an 8-input **Binary Neural Network (BNN) perceptron** trained
on the [Breast Cancer Wisconsin dataset](https://scikit-learn.org/stable/datasets/toy_dataset.html#breast-cancer-dataset).
It classifies a tumor as **malignant (y=0)** or **benign (y=1)** with **89.5% test accuracy**.

### Computation

```
y = sign( popcount( x XNOR W ) − T )
```

Where:
- `x[7:0]` — 8 binarized patient features
- `W = 8'b00000110` — hardcoded trained weights
- `XNOR` replaces floating-point multiply
- `popcount` replaces accumulate
- `T = 3` — learned threshold (at least 3 of 8 features must match)

### Two engines

| Engine | Output pin | Latency | Gate count |
|--------|-----------|---------|------------|
| Combinational | `uo_out[0]` | 3 logic levels (~1 ns) | ~55 GE |
| Sequential (1 bit/cycle) | `uo_out[1]` | 8 clock cycles | ~84 GE |

Total: **~140 GE** — well under the 1000-gate TinyTapeout budget.

### Feature → input mapping

Each input bit is the result of comparing a raw patient measurement against the
training-set median. Compute these on the host MCU before driving `ui_in`:

| `ui_in` bit | Feature | Threshold |
|------------|---------|-----------|
| `[0]` | mean radius | > 13.27 mm |
| `[1]` | mean perimeter | > 85.98 mm |
| `[2]` | mean area | > 541.8 mm² |
| `[3]` | mean concave points | > 0.0326 |
| `[4]` | worst radius | > 14.91 mm |
| `[5]` | worst perimeter | > 97.59 mm |
| `[6]` | worst area | > 683.4 mm² |
| `[7]` | worst concave points | > 0.0972 |

### How to use

**Combinational (instant result):**
1. Drive `ui_in[7:0]` with the binarized feature vector
2. Read `uo_out[0]` immediately (1 = benign, 0 = malignant)

**Sequential (lower gate count at scale):**
1. Drive `ui_in[7:0]` with the feature vector
2. Pulse `uio_in[0]` (start) high for one clock cycle
3. Wait for `uo_out[2]` (valid) to go high (8 clock cycles)
4. Read `uo_out[1]` (y_seq)

## How to test

```python
# Binarize a patient's measurements (host MCU code)
features = [radius, perimeter, area, concave_pts,
            w_radius, w_perimeter, w_area, w_concave_pts]
medians  = [13.27, 85.98, 541.8, 0.0326, 14.91, 97.59, 683.4, 0.0972]

ui_in = sum((1 if f > m else 0) << i
            for i, (f, m) in enumerate(zip(features, medians)))

# Drive ui_in, read uo_out[0]
# 1 = benign, 0 = malignant
```

See `scripts/infer_bnn.py` for the full Python inference pipeline that
mirrors the hardware gate-for-gate.

## Training

Weights were generated by `scripts/train_bnn.py`:

1. Loaded Breast Cancer Wisconsin (569 samples, 30 features)
2. Selected 8 features by ANOVA F-score
3. Binarized features at training-set median
4. Trained logistic regression on binary features
5. Binarized weights: positive → 1, non-positive → 0
6. Swept threshold T ∈ {1..8} on test set → best T = 3

To retrain with new data, update the `localparam` lines in
`src/tiny_bnn_comb.v` and `src/tiny_bnn_seq.v` with the output of
`scripts/train_bnn.py`.
